# DiscordFG

**DiscordFG** (Discord Formatting Guide) is an interactive, web-based reference and tutorial for mastering text formatting on Discord. It is designed to help users—beginners and advanced alike—learn how to use Markdown and other formatting features to enhance their messages on Discord.

[![Open Discord](https://img.shields.io/badge/Open%20Discord-5865F2?logo=discord&logoColor=white&plastic)](discord://)

## What is DiscordFG?

DiscordFG is a comprehensive, visually rich guide that covers:

- All basic and advanced Discord text formatting techniques
- Markdown syntax, code blocks, syntax highlighting, and more
- How to use mentions, links, images, spoiler tags, and lists
- Interactive tooltips, live examples, and a modern, Discord-inspired UI

The guide is authored and maintained by Ghost, and is not affiliated with or endorsed by Discord.

## Features

- **Extensive Table of Contents** for easy navigation
- **Step-by-step formatting tutorials** with live, interactive examples
- **Syntax highlighting** for multiple programming languages
- **Tooltips and visual cues** to explain formatting concepts
- **Modern, responsive design** inspired by Discord’s look and feel
- **No installation required**—just open the HTML file in your browser

## Getting Started

1. Clone or download this repository.
2. Open `DiscordFG.html` in your web browser.
3. Browse the guide, try out formatting, and use the Table of Contents to jump to any section.

## Who is it for?

- Discord users who want to improve their message formatting
- Community managers and moderators
- Anyone interested in Markdown or Discord’s text features
