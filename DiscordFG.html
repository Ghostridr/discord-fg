Basic Formatting

As mentioned, Discord uses Markdown for text formatting. This can have various outcomes and uses depending on the syntax used. Here are some examples of basic formatting options available in Discord:

Italicizing

To italicize text, you can use either an _underscore_ or an *asterisk* before and after the text you want to italicize. For example, _italicize_ or *italicize* will both italicize the text between the underscores or asterisks. This is useful for emphasizing certain words or phrases.

Example This is an example of text that has been italicized using the Markdown syntax.

Bolding

To bold text, you can use either two __underscores__ or two **asterisks** before and after the text you want to bold. For example, __bold__ or **bold** will both bold the text between the underscores or asterisks. This is useful for making text stand out or for highlighting important information. You can do this as well for making a subheading.

Example This is an example of text that has been bolded using the Markdown syntax.

Underlining

To underline text, you can use two ~~tildes~~ before and after the text you want to underline. For example, ~~underline~~ will underline the text between the tildes. This is useful for indicating that text is important or needs to have emphasis.

Example This is an example of text that has been underlined using the Markdown syntax.

Strikethrough

To strikethrough text, you can use two ~~tildes~~ before and after the text you want to strikethrough. For example, ~~strikethrough~~ will strikethrough the text between the tildes. This is useful for indicating that text has been removed or is no longer valid.

Example This is an example of text that has been strikethrough using the Markdown syntax.

Spoiler Tags

To create a spoiler tag, you can use two vertical bars || before and after the text you want to hide. For example, ||spoiler|| will hide the text between the vertical bars until the user clicks on it to reveal the content. This is useful for sharing information that you want to keep hidden until the user chooses to view it. Spoiler tags can be used to hide spoilers, sensitive information, or other content that you want to reveal selectively.

Example Click on this spoiler tag to reveal the hidden text: this was hidden by a spoiler tag.

Escaping

To escape a character in Markdown, you can use a backslash \ before the character you want to escape. For example, \*escaped\* will display as *escaped* instead of italicizing the text between the asterisks. This is useful when you want to display a character as-is without formatting it.

Example How to type escaped format styles will be shown followed by how it will appear in Discord within a code block below:

Text that is italicized (escaped): \*italicized\*
*italicized*

Text that is bolded (escaped): \*\*bolded\*\*
**bolded**

Text that is underlined (escaped): \_\_underlined\_\_
__underlined__

Text that is strikethrough (escaped): \~\~strikethrough\~\~
~~strikethrough~~

A single-line code block (escaped): \`code block\`
`code block`

A multi-line code block (escaped): \`\`\`multi-line code block\`\`\`
```multi-line block```

Syntax Highlighting

To use syntax highlighting, you can use three backticks ``` before and after the text to create a multi-line code block. After the first three backticks you'll want to put the coding language for the kind of syntax highlighting you are wanting. For example, ```md will highlight the text between the backticks based on Markdown highlighting.

Text Formatting

Inline Code

To format text as inline code, you can use a single backtick ` before and after the text you want to format. For example, `inline code` will format the text between the backticks as inline code. This is useful for highlighting code snippets or commands within a message on a single line. You can also use inline code in a sentence to emphasize specific words or phrases. If you use inline code in a code block, it will not format the text as inline code.

Example `Inline code` will display as inline code.

Code Blocks

To format text as a code block, you can use three backticks ``` before and after the text you want to format. For example, ```code block``` will format the text between the backticks as a code block. This is useful for sharing code snippets or longer blocks of code. You can also specify the language for syntax highlighting by adding the language name after the first three backticks, such as ```swift for Swift code.

Example ```Code block``` will display as: 

                Code block
Or, if used as multi-line code block: 

                multi-line
                code
                block

Block Quotes

To format text as a block quote, you can use a greater than sign > before the text you want to format. For example, > block quote will format the text after the greater than sign as a block quote. This is useful for quoting messages or text from other sources. If you use a block quote in a code block, it will not format the text as a block quote. However, if you use three greater than signs >> text it will format the text as a block quote for everything below it in a message.

Example > Block quote will display as:
Block quote
Or, if used as multi-line block quote:
Multi-line
block quote

Lists

To create a list, use a hyphen - before each item. For example, - list item will create a bullet point. For multi-line lists, add a line break between items to organize information clearly. In a code block, lists won't format as lists, but adding spaces before the hyphen - list item will indent the list. For numbered lists, use numbers 1. list item. You can mix hyphens and numbers for multi-line numbered lists, which is useful for ordered lists or instructions. Nested lists can be created by adding more spaces before the hyphen or number, which is helpful for creating sub-lists or outlining steps. You can also use roman numerals i. list item for indented numbered lists.

Example - List item will display as:
  • List item

Or, if used as multi-line list:
  • Multi-line
  • List item

Or, if used as a numbered list:
  1. Numbered list item

Or, if used as multi-line numbered list:
  1. Multi-line
  2. Numbered list item

Or, if used as a nested list:
  • Nested list item
    • Sub-list item

Or, if used as a roman numeral list:
  1. Numbered list item
    2. i. Sub-list item
    ii. Sub-list item
  2. Numbered list item

Headers

To create a header, use a pound sign # before the text you want to format. For example, # header will create a header. You can use up to three pound signs for different header sizes, with one being the largest and three being the smallest. This is useful for organizing information into sections or highlighting important details. Headers can be used to create sections for longer messages or documents, making it easier for readers to navigate the content.

Example # Header will display as:

Header


Or, if used as a smaller header: ## Header will display as:

Header


Or, if used as the smallest header: ### Header will display as:

Header

Small Text

To create small text, us a hyphen sign - and a hashtag sign # before the text you want to format. For example, -# small text will create a small text. This is useful for indicating that text is less important or needs to have emphasis. You can not use small text in a sentence to emphasize specific words or phrases. If you use small text in a code block, it will not format the text as small text.

Example -# Small text will display as:

Small text.

Compared to normal text.

This can be useful for indicating that text is less important or needs to have emphasis.

Mention Features

Discord supports a variety of advanced features that can enhance your messages and make them more engaging. Here are some examples of advanced features you can use in Discord:

Common Mentions

Users can mention other users, roles, anyone online, or everyone in a server to get their attention or notify them about a message. Channels and categories can also be mentioned to create links to those elements. Mentions are a useful way to interact with others in Discord and make messages more interactive. Here are some common mentions you can use in Discord:

User Mentions

To mention a user by their username, you can use the @ symbol followed by their username. For example, @Ghost will mention the user with the username "Ghost". This is useful for getting someone's attention or notifying them about a message. You can also mention multiple users in a message by separating the mentions with a space. Mentions will create a link to the user's profile, allowing others to click on it to view more information.

Example Hey there, @Ghost! Click the mention to see the profile popup!

Ghost
.Ghost
ROLES
Admin Developer
Self-taught developer, passionate about learning.

Role Mentions

To mention a role in a server, you can use the @ symbol followed by the role name. For example, @Admins will mention the role with the name "Admins". This is useful for notifying all members of a specific role about a message or event. Role mentions will create a link to the role, allowing others to click on it to view more information.

Example To mention a role: @Admins. This will show as: @Admins.

Everyone Mentions

To mention everyone in a server, you can use the @everyone command. This will notify all members of the server about a message or event. Everyone mentions are useful for sharing important announcements or updates with the entire community. It is important to use everyone mentions sparingly to avoid spamming or overwhelming members with notifications. It is usually frowned upon to use everyone mentions for non-urgent or unnecessary messages, so be mindful of when and how you use them: announcements, server-wide events, or important updates are good examples of when to use everyone mentions.

Example To mention everyone: @everyone. This will show as: @everyone.

Here Mentions

To mention everyone online in a server, you can use the @here command. This will notify all members who are currently online about a message or event. Here mentions are useful for getting the attention of active members and engaging with the community in real-time. It is important to use here mentions sparingly to avoid spamming or overwhelming members with notifications. Here mentions are typically used for time-sensitive or urgent messages that require immediate attention or participation. Since here mentions will only notify members who are currently online, so it is a good way to reach an active audience quickly and efficiently.

Example To mention everyone online: @here. This will show as: @here.
Those who are "Online", "Idle", or "Away" will receive the notification. Those who are "Do Not Disturb" or "Offline" will not receive the notification.

Channel Mentions

To mention a channel in a server, you can use the # symbol followed by the channel name. For example, #general will mention the channel with the name "general". This is useful for creating links to specific channels in a message or directing members to a particular channel for discussions or announcements. Channel mentions will create a link to the channel, allowing others to click on it to go to the channel directly. This is a convenient way to navigate between channels and keep conversations organized within a server. Channel mentions are commonly used to reference specific channels in messages or provide context for discussions. Discord will also generate a channel mention if you copy the channel's link and paste it into a message, which will then link to the message directly within the mentioned channel. If a channel has a space in the name then Discord automatically replaces the space with a hyphen so channel names are always one word.

Example To mention a channel: #general. This will show as: #general.
Channels that are hyphenated will be mentioned as one word, such as #general-discussion will show as #general-discussion.

Advanced Mentions

In addition to common mentions, Discord also supports advanced mentions which utilizes ID-based mentions to reference specific users, roles, or channels. These advanced mentions allow for more precise targeting of mentions as they are based on unique identifiers rather than names. This can be useful for automating mentions or creating custom commands that require specific user or role references. Advanced mentions are commonly used in bots, scripts, or other automated systems that interact with Discord servers and users. Here are some examples of advanced mentions you can use in Discord:

Getting IDs

To get the ID of a user, role, or channel in Discord, you can enable Developer Mode in your user settings. Once Developer Mode is enabled, you can right-click on or escape (\) a user, role, or channel and select "Copy ID" to copy the unique identifier to your clipboard. This ID can then be used in messages or commands to reference the specific user, role, or channel. Developer Mode is a useful feature for accessing advanced features in Discord and customizing your experience with additional options and settings. It is commonly used by developers, bot creators, or power users who need to access specific information or perform advanced actions in Discord. This works for emojis as well, allowing you to copy the ID of an emoji to use in custom commands or messages.

User ID Mentions

To mention a user by their ID, you can use the <@USER_ID> format. This will create a mention that links to the user's profile based on their unique identifier. User ID mentions are useful for referencing specific users in messages or commands that require precise targeting. User IDs are unique to each user and can be used to identify users across different servers or platforms. User ID mentions are commonly used in bots, scripts, or other automated systems that interact with Discord servers and users. User IDs are a reliable way to reference users in messages or commands that require specific user references.

Example To mention a user by their ID: <@123456789012345678>. This will show as: @Ghost.

Role ID Mentions

To mention a role by its ID, you can use the <@&ROLE_ID> format. This will create a mention that links to the role based on its unique identifier. Role ID mentions are useful for referencing specific roles in messages or commands that require precise targeting. Role IDs are unique to each role and can be used to identify roles across different servers or platforms. Role ID mentions are commonly used in bots, scripts, or other automated systems that interact with Discord servers and roles. Role IDs are a reliable way to reference roles in messages or commands that require specific role references.

Channel ID Mentions

To mention a channel by its ID, you can use the <#CHANNEL_ID> format. This will create a mention that links to the channel based on its unique identifier. Channel ID mentions are useful for referencing specific channels in messages or commands that require precise targeting. Channel IDs are unique to each channel and can be used to identify channels across different servers or platforms. Channel ID mentions are commonly used in bots, scripts, or other automated systems that interact with Discord servers and channels. Channel IDs are a reliable way to reference channels in messages or commands that require specific channel references.

Example To mention a channel by its ID you'll need to follow this format: <#123456789012345678>. This will show as: #general.

Command Mentions

To mention a command in a message, you can use the command (/test). Before sending the message, a description of the command will appear above the input field. Right-click on this popup and select "Copy ID" to copy the unique identifier associated with the command. This Command ID can then be used in messages or commands to reference that specific command. Command mentions are especially useful when discussing or sharing bot functionalities, as they allow users to click the mention and have Discord automatically pre-fill the command for them. Since Command IDs are unique to each command, they ensure accurate identification across different servers and platforms for the same bot. This feature is particularly beneficial for bots with a large number of commands, making it easy for users to refer to specific commands efficiently.

Example To mention a command by its ID you'll need to follow this format: </test:123456789>. This will show as: /test.
You can also try /help or /info. Click one of these command mentions to test it out yourself.
